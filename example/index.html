Before and after event cleanup

Native listeners need you to keep the same element, callback, and cleanup path. easy-events keeps that small lifecycle in one place.

Native addEventListener

You manage the element lookup and callback reference yourself.

const button = document.querySelector("#native-target");
let nativeClickCount = 0;

const nativeHandler = () => {
  nativeClickCount += 1;
};

button?.addEventListener("click", nativeHandler);

// Later...
button?.removeEventListener("click", nativeHandler);
Native listener is not attached.

easy-events

The helper resolves the selector and gives you cleanup.

import { easyEventListener } from "easy-events";

let cleanup = easyEventListener("#easy-target", "click", () => {
  easyClickCount += 1;
});

// Later...
cleanup?.();

// Or remove the managed listener directly.
easyEventListener.remove("#easy-target", "click");
easy-events listener is not attached.
